---
title: Installation
description: Add the spikyuni marketplace to Claude Code or Codex, and install a plugin from it.
---

Adding a marketplace registers the catalog. It installs nothing until you install a plugin from it.
The marketplace is named `spikyuni`, and that is the name after the `@` in every install command.

## Claude Code

```
/plugin marketplace add spikyuni/marketplace
/plugin install <plugin>@spikyuni
```

Both commands also run outside a session as `claude plugin marketplace add` and
`claude plugin install`. Refresh the catalog with `/plugin marketplace update`. Claude Code does not
auto-update third-party marketplaces unless you turn that on under `/plugin` → Marketplaces.

## Codex

```
codex plugin marketplace add spikyuni/marketplace
codex plugin add <plugin>@spikyuni
```

Codex installs with `plugin add`, not `plugin install`.

Codex lists every plugin that ships as an npm package. `quill` and `research-workbench` ship from
GitHub instead, and Codex cannot install a GitHub source from a marketplace, so they install from
Claude Code only for now.

## GitHub Copilot CLI and Cursor

Not available yet. The catalogs are generated by
[universal-plugin](https://github.com/cyberuni/universal-plugin), which writes a Copilot CLI or
Cursor entry only for a plugin whose source is a directory inside the marketplace repository. This
marketplace lists plugins by reference and holds no plugin source, so it has no Copilot CLI or
Cursor catalog yet. Cursor also has no command that adds a repository catalog: an admin imports one
as a team marketplace.
